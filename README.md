# GingaSegura - MVP (Associacao Martelo Predador)

Aplicacao web progressiva (Mobile-First PWA) alinhada ao ODS 3 (Meta 3.d) para registro agil de chamadas em lote (offline-first) e acionamento imediato de emergencia medica.

## Como executar
```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
```
